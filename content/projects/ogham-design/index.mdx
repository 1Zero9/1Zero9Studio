## The brief

A tattoo creation tool with minimal interaction: feed in an idea, get back a
mockup or a plan for how to proceed. First style is Ogham script.

## The build

- **Proof before build** — Ogham is a real, rule-based alphabet. A bare AI
  text prompt hallucinates a fake alphabet; the app instead renders the
  correct glyphs deterministically first, then hands that to Gemini 3 Pro
  Image as a reference for photorealistic styling only. Tested against real
  Gemini output before any app code existed.
- **Cloudflare D1, not Postgres** — the Supabase free tier was already at
  its project cap; D1 removed an entire layer (no Hyperdrive, no external
  account) for a small-group app with no cross-project data needs.
- **Shared-password gate** — a known small group, not public — cookie-based
  session, HMAC-signed.

## Why it matters

Server-side WASM rendering on Cloudflare Workers failed three separate ways
before working (native bindings, runtime WASM compile restrictions, Next's
bundler mis-parsing a static wasm import) — each confirmed only by testing
the actual live deploy, not by a clean build. That lesson is now a
CONVENTIONS.md guardrail for the next Cloudflare project.
