## The Concept

Territory War is an experiment in bringing classic turn-based tactical strategy to the modern browser without heavyweight game engines or app store friction.

## Current Workbench State

- **Procedural Map Engine** — Dynamic node-and-grid map generation that creates fresh tactical layouts each match.
- **State & Synchronization** — Lightweight real-time state synchronization keeping turns deterministic across players.
- **Canvas Rendering** — High-performance 60fps vector canvas interface with smooth troop movement animations.

## Next Milestones

1. Real-time lobby and matchmaking system.
2. Fog of war mechanics and sound design.
